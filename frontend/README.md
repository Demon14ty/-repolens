# RepoLens frontend

Next.js (App Router, TypeScript, Tailwind CSS v4) web app for RepoLens.

```bash
npm install
npm run dev     # http://localhost:3000, expects the API on http://localhost:8000
npm run lint
npm run build
```

`lib/types.ts` mirrors `../api/schemas.py`. Setup, environment variables and Vercel deployment are documented
in the [root README](../README.md).
